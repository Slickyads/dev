# zerene

A Generative Engine Optimization (GEO) research and strategy project for Zerene's luxury wellness & executive gifting brand, focusing on the Saudi Arabian market.

## Project Overview

This repository contains GEO strategy documentation, SEO research, and prompt libraries for optimizing Zerene's visibility in AI search engines, particularly for B2B corporate gifting in KSA.

## Key Resources

- **geo_review.html** — Interactive HTML report with GEO progress metrics, audit findings, and recommended action plan
- **seo/** — SEO research files, keyword analysis, and monitoring data
- **pdf/** — PDF documents including brand reports and audit briefs
- **Keyword_Brief_for_Copywriter.md** — Content brief aligned with GEO intent taxonomy
- **otterly_prompts_optimized.csv** — CSV of core prompts for Otterly.ai import

## GEO Strategy Summary

**Target Market:** KSA luxury wellness & executive gifting (Tier 3–4 B2B intent)

**Core Challenge:** Zero product specs, pricing, and JSON-LD schema prevent AI engines from recommending Zerene for category queries.

**Current AI Share of Voice:** 20% (need 25%+ benchmark)

**Key Gaps:**
- 0% KSA category intent — competitors win all non-branded queries
- Missing SAR pricing and 200ml/100ml product specs
- No JSON-LD FAQPage schema for AI extraction
- No dedicated /ksa landing page or local address signal

## Getting Started

1. Review `geo_review.html` for the full audit findings and prioritized action plan
2. Use `otterly_prompts_optimized.csv` to import core prompts into Otterly.ai
3. Focus on blue-ocean (Tier 3/4) prompts: healthcare, corporate wellness, interior architecture
