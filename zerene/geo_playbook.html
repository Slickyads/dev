GEO Scoring Methodology

GEO Citation Score (Per Prompt) = (Direct Link Citation × 40) + (Brand Mention × 30) + (Top 3 Rank Position × 30)

Each prompt is scored on four dimensions and averaged for the overall GEO score (0-100):

  • Heading Prompt Match: H1/H2 headers match user prompts verbatim
  • 40-Word Answer Blocks: Each header has a concise 40-word summary for LLM extraction
  • Fact Density & Statistics: Minimum 3 verifiable metrics per 500 words
  • JSON-LD Schema Integration: FAQPage, Article, Organization, and Product schemas for AI extraction
Validation Gate: A prompt enters the Core Baseline only if ALL 5 conditions pass:
  • ✅ Non-brand (not direct brand query)
  • ✅ Sounds like real B2B buyer
  • ✅ Commercial/B2B intent, not consumer retail
  • ✅ Intent fit ≥ 80 (on 0-100 scale)
  • ✅ Consistent across 3 runs

Strategic Recommendations

Top 5 Priority Actions (Next 30 Days)

  1. Launch 40-Word Answer Blocks under all H2/H3 headers for top 20 non-brand queries. This directly addresses the low citation rates (only 1 click from 2,600+ non-brand impressions) and improves LLM extraction.
  2. Deploy JSON-LD FAQPage Schema on all pillar pages. Currently only 3.5% of answers have structured data, far from the AI-optimized standard.
  3. Develop Arabic B2B Landing Pages targeting Ramadan/National Day seasonal prompts. Arabic query ranking in Top 5 (Pos 3.83) presents opportunity but requires dedicated localized content.
  4. Implement Weekly SoV Tracking using automated scripts. Current quarterly measurement delays timely optimization of high-priority prompts.
  5. Build Off-Page Authority via GCC B2B directory listings and industry press. Currently, 59.2% of ChatGPT citations lack schema/entity validation.
Key Insight: The biggest gap is structured data (JSON-LD) and answer extraction readiness. 80% of high-performing pages (scored 76/100) have strong fact density, while lower-scoring pages (58/100) lack answer blocks and schema.

Content Writer SOP & Standards

4-Step Writing Process

  1. ICP & Intent Identification: Define if the piece targets B2B procurement (hotels, corporate gifting) or AI informational research.
  2. Bilingual Keyword Assignment: Provide 2-3 English and Arabic keywords/prompts from the Master Bilingual Keyword Matrix.
  3. CSQAF Fact Density: Include at least 3 verifiable metrics (MOQ, IFRA compliance, clinical studies) and structured comparison tables.
  4. 40-Word Answer Blocks: Write concise 40-word summary under each H2 header for instant LLM extraction.

Structural Requirements for GEO:

  • H1 header must match primary user prompt verbatim
  • 40-word answer blocks under every H2
  • Fact density: at least 3 verifiable metrics
  • Bilingual format: English/Arabic with proper RTL/LTR tags
  • JSON-LD FAQPage and Article schema integration
