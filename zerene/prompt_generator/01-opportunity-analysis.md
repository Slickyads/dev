# 01 - Opportunity Analysis

## Input required

- `00-shared-context.md`
- Data from spreadsheet tab: `form`

## Instruction

Using the SHARED CONTEXT and the INPUT DATA below, perform an opportunity analysis for Zerene.

Do not generate prompts, keywords, or content in this step.

## INPUT DATA

```text
[PASTE DATA FROM SPREADSHEET TAB: form]
```

If spreadsheet access is unavailable, ask the user to paste the required fields from the `form` tab before continuing.

## Task

Identify and prioritize opportunities for Zerene across:

1. Buyer intents
2. High-value AI prompts and search queries
3. Offer tiers
4. Audience segments
5. Seasonal and cultural moments
6. Markets and languages
7. Content gaps
8. Competitor or category benchmark gaps, if competitor data is provided

## Seasonal and cultural opportunities

Consider:

- Ramadan
- Eid
- Saudi National Day
- Year-end gifting
- Corporate events
- Hospitality openings
- Wellness projects

## Prioritization criteria

Rank opportunities by:

1. Commercial and lead-generation value
2. Brand visibility opportunity
3. Share-of-voice opportunity
4. Seasonal timing
5. Content feasibility
6. Topical authority value

## Output format

Return only this compact table:

| Opportunity ID | Opportunity Theme | Target Buyer Intent | Offer Tier | Audience | Market | Language | Search / AI Prompt Opportunity | Business Objective | GEO Objective | Priority | Seasonal Timing | Data Gaps |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

## Output limit

Return the 25 highest-value opportunities only.
